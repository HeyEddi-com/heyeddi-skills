# HeyEddi Video Skills

The video skill by itself. Source of truth is `HeyEddi-com/heyeddi-skills`.

Install only this skill:

```bash
npx skills add HeyEddi-com/heyeddi-skills -a claude-code cursor -g -y --skill heyeddi-video
```

It also uses the official HyperFrames skills; `heyeddi-video` lists the command.
