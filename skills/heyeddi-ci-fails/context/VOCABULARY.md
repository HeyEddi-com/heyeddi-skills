# Vocabulary: HeyEddi CI fails

- **ci-fails report**: ephemeral `.heyeddi/docs/pr-<N>-ci-fails.md` — never commit
- **/heyeddi fails**: App command for hosted failed-Check analysis (may be billable)
- **statusCheckRollup**: gh PR Checks summary used by `fetch_failing_checks`
- **authorize merge**: required before any merge after fixes
