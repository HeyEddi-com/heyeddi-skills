# Vocabulary: HeyEddi CI respond

- **HeyEddi finding**: comment with `<!-- heyeddi-ci-review`, debate marker, or HeyEddi bot login
- **ci-tracking / ci-replies / ci-posted**: ephemeral artifacts under `.heyeddi/docs/` — **never commit**
- **discover_and_verify**: stack-agnostic evidenced commands only (npm/pytest/go/cargo/make)
- **authorize merge**: required phrase before any merge attempt
- **Decline + feedback**: in-thread decline; optional debate / support mail; no FP API
