# Vocabulary

- **stack.json**: Single `.heyeddi/` file for tech (other skills) and prefs (`@heyeddi-setup`).
- **Preset**: `main_staging_dev` or `main_dev` — always maps at least production + staging.
- **custom_workflow**: Escape hatch string when the team does not use a preset (gitflow, etc.).
- **ask / auto**: Agent must confirm, or may act on feature branches without asking.
