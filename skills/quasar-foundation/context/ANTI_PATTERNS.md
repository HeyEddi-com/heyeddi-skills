# Anti-patterns

- Using `<q-table>`, `<q-select>`, or `<q-input>` for dense SaaS data. That work is PrimeVue Aura.
- Hand-rolled `position: sticky` headers instead of `<q-header>`.
- A second primary color that ignores `--q-primary`.
- Tailwind classes on Quasar markup.
- Adding React Native or Ionic beside Quasar for the same shell.
