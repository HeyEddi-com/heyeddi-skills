# Vocabulary

- **Frame:** `<q-layout>`, `<q-page-container>`, `<q-page>`.
- **Drawer:** `<q-drawer>` with swipe and mini mode. Not a PrimeVue sidebar.
- **Native target:** `quasar build -m capacitor` (mobile) or `quasar build -m tauri` (desktop).
- **Shell primitive:** only the components listed in this skill's responsibility table.
