`@heyeddi` runs this skill first (one pass, tokens), then `@heyeddi-design` records the tokens in `.heyeddi/design.md` and hands off to Vue or Flutter.

## Operate / settings (hi-fi bar)

```
Design the settings suite: profile, notifications, billing.
```

**Reject:** one gray card per section with a multiline paste of labels and values.

**Pass:** `@taste-penpot` places separate field rows on an 8px grid, reads `layout` and `parentId` back before calling a board hi-fi, and looks at the Penpot canvas. `hifi.html` is only the hi-fi artifact when no Penpot boards were written. `@heyeddi-design` craft refuses text-walls and a Penpot file signed off from the HTML mirror.
