# Vocabulary: visual auditor

- **Fast widths:** 375 (mobile), 768 (tablet), 1440 (desktop) — iteration.
- **Done widths:** 375, 430, 768, 1024, 1440, 1920 — flagship/marketing before calling done (`--preset done`).
- **Density:** comfortable touch targets (min 44px) on mobile widths.
- **Contrast on the plane:** edges and links must remain legible on their background; never put edge/link color on washed paper.
- **Logo-off test:** if removing the brand makes the UI look like another startup, it is not done.
