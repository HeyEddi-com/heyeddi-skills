# Vocabulary

- **Wizard:** a `@clack/prompts` sequence (`intro`, `text`, `select`, `confirm`, `outro`) that handles `isCancel`.
- **Status box:** `consola.box` plus `consola.start` / `consola.success` for a running task.
- **ANSI palette:** the 16 colors `picocolors` exposes. No hex, no 256-color codes.
