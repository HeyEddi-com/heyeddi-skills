# Anti-patterns

- A Vue page, Canvas, or HTML string that pretends to be the CLI.
- `console.log` banner art for a flow that clack or consola already covers.
- Continuing after `isCancel` returns true.
- Truecolor or hex in terminal output.
- Importing Quasar or PrimeVue into a CLI package.
- Finishing a CLI without running it and reading stdout.
- Sending a terminal UI through `@visual-verification` or a browser screenshot.
