# Vocabulary

- **Aura:** the PrimeVue theme preset from `@primevue/themes/aura`. Prefix `p`. Dark selector `.dark-mode`.
- **Hybrid harmony:** Quasar CSS first, PrimeVue second, MotionPlugin third. `cssLayer: false`.
- **Data primitive:** `DataTable`, `Column`, `TreeTable`, `MultiSelect`, `TreeSelect`, `CascadeSelect`, `TieredMenu`, `ContextMenu`, `Breadcrumb`, `Tag`, `Badge`, `ProgressBar`.
