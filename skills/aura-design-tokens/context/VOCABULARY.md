# Vocabulary

- **App role:** `--app-bg`, `--app-surface-card`, `--app-border`, `--app-text-main`, `--app-text-muted`.
- **Aura source:** PrimeVue variables `--p-surface-*`, `--p-text-color`, `--p-primary-color`.
- **Quasar bridge:** `--q-primary`, `--q-secondary`, and in dark mode `--q-dark`, `--q-dark-page`.
- **Dark switch:** the `.dark-mode` class, shared with PrimeVue `darkModeSelector`.
