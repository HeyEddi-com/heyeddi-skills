# Vocabulary

- **Loop:** write code, HMR on port 5173, Playwright MCP screenshot, look, fix.
- **Playwright MCP:** `@playwright/mcp`. Tools: `browser_navigate`, `browser_resize`, `browser_take_screenshot`.
- **Desktop viewport:** `browser_resize` to 1440 by 900, then a screenshot.
- **Mobile viewport:** `browser_resize` to 390 by 844, then a screenshot.
- **Recorded review:** `@visual-auditor`. This skill does not replace that file.
