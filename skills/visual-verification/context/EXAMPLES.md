# Examples

Dashboard after a Quasar shell and a PrimeVue table:

1. `browser_navigate` to `http://localhost:5173/#/dashboard`.
2. `browser_resize` to width 1440, height 900. `browser_take_screenshot` to `.heyeddi/docs/visual-verification/dashboard-desktop.png` with `scale: css` and `fullPage: true`.
3. `browser_resize` to width 390, height 844. `browser_take_screenshot` to `.heyeddi/docs/visual-verification/dashboard-mobile.png`.
4. If the drawer covers the table on mobile, change the Quasar breakpoint and screenshot mobile again.
